# Telegram OLED Electric Lime Themes ⚡️🟢

A collection of clean, high-contrast, pure black OLED themes for **Telegram Desktop** and **Telegram Android**.

Designed to maximize battery savings on OLED/AMOLED screens, maintain zero gradient artifacts during scrolling screenshots, and provide an ultra-clean aesthetic with Electric Lime (`#bcf600`) accents.

---

## 🎨 Themes Included

### 1. `OLED Electric Lime` (Classic Signature)
* **Cloud Link:** [t.me/addtheme/OLED_Electric_Lime](https://t.me/addtheme/OLED_Electric_Lime)
* **Backgrounds:** Pure OLED Black (`#000000`).
* **Outgoing Message Bubbles:** Solid Dark Olive Green (`#293800`) with zero gradient and zero shadow artifacts (ideal for scrolling screenshots on mobile).
* **Incoming Message Bubbles:** Subtle Dark Gray (`#141414`).
* **Accents:** Electric Lime (`#bcf600`).
* **Chat List:**
  * Active Chat: `#293800` (matching outgoing bubbles).
  * Hover Chat: `#182200`.
  * Folder Tags: Unified Electric Lime pills.
  * Muted Unread Badges: Muted matte olive (`#4a5932`) with legible black digits.
  * Saved Messages: Pure black circle with Electric Lime bookmark icon.

### 2. `OLED Electric Lime - Pure Black` (Experimental Void / Stealth)
* **Concept:** Floating white typography on pure black infinite void.
* **Message Bubbles:** **No visible bubble backgrounds** (`#000000`) for both incoming and outgoing messages.
* **Message Text:** Crisp, razor-sharp pure white (`#ffffff`).
* **Auxiliary Elements:** Timestamps, dates, and checkmarks are intentionally dimmed (`#556635` / `#666666` / `#7ea300`) to let the message text take full center stage without distraction.
* **Accents:** Electric Lime (`#bcf600`) for unread counters, active selections, and interactive controls.

## 🚀 Installation Guide

### Telegram Desktop (Windows, macOS, Linux):
1. Send the `.tdesktop-theme` file to your Telegram (e.g. to **Saved Messages**).
2. Click on the file inside Telegram.
3. In the preview window, click **Apply this theme**.

### Telegram Android:
1. Send the `.attheme` file to your Telegram.
2. Tap on the file inside Telegram.
3. Tap **Apply**.

## ☁️ How to Update Cloud Theme (`t.me/addtheme/...`)

To update an existing cloud theme link without creating a new URL:

1. **Be logged in with the creator's account:** The theme update must be performed from the Telegram account that originally registered `https://t.me/addtheme/OLED_Electric_Lime`.
2. **Apply the updated theme locally:**
   * **On PC:** Open `OLED-Electric-Lime.tdesktop-theme` and click *Apply*.
   * **On Android:** Open `OLED-Electric-Lime.attheme` and click *Apply*.
3. **Save changes to the Cloud link:**
   * **On PC:** Go to **Settings** $\rightarrow$ **Chat Settings** $\rightarrow$ Click the `⋮` (three dots) menu in the themes block $\rightarrow$ Choose **"Update theme for all"** or **"Save theme"**.
   * **On Android:** Go to **Settings** $\rightarrow$ **Chat Settings** $\rightarrow$ Click the `⋮` (three dots) menu in the top right $\rightarrow$ Choose **"Save changes to theme"** $\rightarrow$ Select your theme from the list.
4. Telegram will push the updated file to the existing slug (`OLED_Electric_Lime`), preserving the exact same link for everyone.
